💬 Role: User vstup

Člověk zadá instrukci přirozeným jazykem. Konverzace začíná system promptem (není vidět) + první user zprávou.

🧠 Reasoning / Thinking uvnitř LLM

LLM interně uvažuje nahlas — analyzuje úkol, plánuje kroky, rozhoduje se, který nástroj zavolat a s jakými parametry.

🔨 Tool calls akce

Agent volá externí nástroje (webfetch, bash, read, grep). LLM vygeneruje JSON s názvem nástroje a parametry; runtime ho provede.

🌍 Tool output výsledek

Výstup nástroje se vloží zpět do kontextu LLM jako systémová zpráva. LLM ho zpracuje a rozhodne o dalším kroku.

🤖 LLM inference jádro

Každý cyklus (user → thinking → tool → output → thinking → ...) je jedna nebo více LLM inferencí.

🔗 Message roles kontext

Konverzace se skládá z messages s rolemi: system, user, assistant, tool. Každá má jinou váhu a chování.

💡 Shrnutí — cyklus AI agenta

  • User message — člověk zadá úkol přirozeným jazykem.
  • System prompt (skrytý) — definuje chování, dostupné nástroje, pravidla.
  • Thinking / Reasoning — LLM interně analyzuje, plánuje, rozhoduje. Není určeno uživateli.
  • Tool call — LLM vygeneruje strukturovaný JSON s názvem nástroje a parametry. Runtime (opencode) ho provede.
  • Tool output — výsledek se vloží do kontextu jako tool role zpráva. LLM ho zpracuje.
  • Dokud není úkol hotov, agent opakuje: reasoning → tool call → output → reasoning → ...
  • Assistant response — když je úkol splněn, LLM vygeneruje finální odpověď pro uživatele.
  • Message roles — system (instrukce), user (vstup), assistant (výstup LLM), tool (výstup nástroje). Každá má jiné chování v kontextovém okně.
